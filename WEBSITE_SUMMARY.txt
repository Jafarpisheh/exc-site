## 🆘 Troubleshooting

### Port Already in Use
```bash
npx http-server -p 9999  # Use different port
```

### Images Not Loading
- Check image names are 1.jpg, 2.jpg, etc.
- Ensure they're in correct folder
- Try clearing browser cache

### Videos Not Playing
- Check videos are in MP4 format
- Ensure file is named 1.mp4
- Try different browser

### Form Not Working
- Check console for errors (F12)
- Ensure all required fields filled
- Try clearing localStorage: `localStorage.clear()`
