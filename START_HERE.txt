💡 USEFUL COMMANDS
════════════════════════════════════════════════════════════════════════════

Start website (port 8888):
  npx http-server -p 8888

Start website (port 9999):
  npx http-server -p 9999

Using Python instead:
  python3 -m http.server 8888

View all inquiries (in browser console - F12):
  console.table(JSON.parse(localStorage.getItem('inquiries')))

Clear all stored inquiries:
  localStorage.clear()

Kill web server (if stuck):
  pkill -f http-server

🆘 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

"Port already in use" error:
  → Use different port: npx http-server -p 9999

Images not showing:
  → Check browser console (F12)
  → Verify images are 1.jpg, 2.jpg, etc (lowercase)
  → Ensure they're in products/xc-12/images/ folder

Videos not playing:
  → Ensure video is named 1.mp4 (lowercase)
  → Use MP4 format for compatibility
  → Try different browser

Form not working:
  → Open console (F12) and check for errors
  → Fill all required fields (marked with *)
  → Try clearing browser cache

Still stuck?
  → Check README.md for detailed troubleshooting
  → Open browser developer tools (F12)
  → Check console for error messages
