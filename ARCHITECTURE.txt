═══════════════════════════════════════════════════════════════════════════════
                            DATA FLOW DIAGRAM
═══════════════════════════════════════════════════════════════════════════════

USER VISITS HOME PAGE
        ↓
   index.html
        ↓
   app.js: loadProducts()
        ↓
   Loop through products array
        ↓
   Load first image from each product folder
        ↓
   Display product cards on screen
        ↓
   USER CLICKS "View Details"
        ↓
   Navigate to product-detail.html?product=xc-12
        ↓
   product-detail.js: loadProductDetails()
        ↓
   ├─ Load all images (1.jpg - 5.jpg)
   ├─ Load video (1.mp4)
   ├─ Display specs from product info
   ├─ Link to specs.pdf
   └─ Setup inquiry form
        ↓
   USER BROWSES PRODUCT
        ↓
   USER SUBMITS INQUIRY
        ↓
   Form Data Collected
        ↓
   Stored in Browser's localStorage
        ↓
   Success Message Shown
        ↓
   Admin can access data via browser console

Each Inquiry Contains:
┌─────────────────────────────────────────┐
│ {                                       │
│   productId: "xc-12",                   │
│   productName: "XC-12 Excavator",       │
│   name: "John Doe",                     │
│   email: "john@example.com",            │
│   phone: "+1-555-123-4567",             │
│   company: "ABC Construction",          │
│   message: "Interested in...",          │
│   timestamp: "2026-03-14T10:30:00Z"     │
│ }                                       │
└─────────────────────────────────────────┘

Storage Location: Browser's localStorage
Key: "inquiries"
Value: JSON array of all inquiry objects
