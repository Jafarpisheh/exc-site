💡 QUICK TIPS
═══════════════════════════════════════════════════════════════════════════════

To View Customer Inquiries:
  1. Press F12 (Developer Tools)
  2. Go to Console tab
  3. Paste: console.table(JSON.parse(localStorage.getItem('inquiries')))
  4. See all submitted inquiries!

To Customize Company Name:
  1. Open index.html
  2. Find "BW-Bagger"
  3. Replace with your company name
  4. Save and refresh

To Change Colors:
  1. Open styles.css
  2. Find color codes (#1e3a8a for blue)
  3. Replace with your colors
  4. Save and refresh

To Add More Products:
  1. Create products/xc-25/ folder
  2. Add images, video, specs.pdf
  3. Edit app.js and add to products array
  4. Save and refresh
